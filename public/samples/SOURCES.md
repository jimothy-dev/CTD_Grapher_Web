# Public sample casts

Casts from other instruments, places and decades, for trying the app and
testing the parser. Loaded by the "other public casts" button. They
are not a survey: positions are scattered across the world, so they suit
the Profiles page, and the Transect page only as a stress test.

| File | Instrument | Source | Terms |
|---|---|---|---|
| NCEI_GulfOfMexico_2010_SBE9.cnv | SBE 9, NOAA Ship Gordon Gunter, 2010 | NOAA NCEI accession 0069067, `2010_0528_001/001-H_bin_avg.cnv` | US government work, public domain |
| OOI_Pioneer_2015_SBE9.cnv | SBE 9, OOI Pioneer array shipboard CTD | Rutgers OOI data review archive, `CP02PMCI_D4_at31007.cnv` | OOI data are freely available; cite the Ocean Observatories Initiative |
| Nansen_2008_SBE9.cnv | SBE 9, R/V Dr. Fridtjof Nansen, 2008 | castelao/seabird sample data, `sta0860.cnv` | MIT licence (Guilherme Castelão) |
| Hakai_Quadra_2024_SBE19plus.cnv | SBE 19plus V2, Hakai Institute, Quadra Island | cioos-siooc/ocean-data-parser test files | Hakai Institute data, CC BY 4.0 |

Two of the four carry no position in the header (Hakai, and the OOI file's
header position is duplicated in latitude/longitude columns), which is
useful for checking the position boxes.
